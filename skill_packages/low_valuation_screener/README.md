# 低估值个股筛选 Skill

根据宿主提供的最新每日估值截面，筛选 PE(TTM) 和 PB 均为正且符合可选上限的股票。两项指标分别按截面升序计算百分位排名，均值作为估值分数，低分优先；同分按股票代码排序。

参数：top_n（默认 20，范围 1–500）、max_pe、max_pb。Skill 从标准输入读取单个 x2stock.skill.v1 JSON 对象，并向标准输出写入单个 JSON 响应；诊断日志写入标准错误。

将本目录内容打包为 ZIP，确保 manifest.json 位于 ZIP 根目录，然后在平台 Skill 管理页安装。安装会执行包内 Python 代码，只应安装可信来源的包。
